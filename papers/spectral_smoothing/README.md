# Smoothing Bitstring Distributions

A paper that grew out of the blog post `posts/XanaduSpectralmethodsPaper`, which works through
Belis et al., *Spectral methods: crucial for machine learning, natural for quantum computers?*
(arXiv:2603.24654).

- `paper.tex`, `refs.bib`, `e4_section.tex`: LaTeX sources (`paper.pdf` is the compiled version)
- `figures/`: figures generated by the experiments
- `experiments/hypercube.py`: numerical core (Walsh transform, Laplacian, filters, samplers, P1 solver)
- `experiments/run_experiments.py`: experiments E1 to E6 (results go to `experiments/results/*.json`)

E3 imports `experiments/test_n20_support_equivalence.py` from the repository root.

## Rebuild

```bash
cd papers/spectral_smoothing/experiments
python run_experiments.py            # or a subset: e1 e2 e3 e4 e5 e6 (needs numpy, scipy, matplotlib)
cd ..
latexmk -pdf paper.tex
```
